# 읽기·메뉴·위젯

상위 문서: [AGENTS.md](../../AGENTS.md)

메뉴 항목은 `provider`와 `objectId`를 가진 `kind: 'plugin'`을 사용할 수 있습니다. 등록된 해석기가 검증된 공개 링크/제목을 반환하며, 누락되었거나 실패한 기여 유형은 저장된 항목을 지우지 않고 생략됩니다. 코어 홈/사용자 지정/콘텐츠/용어/아카이브 유형도 같은 레지스트리를 사용합니다. 메뉴와 위젯 저장 필터는 저장 전에 검증되며, 수명 주기 액션과 읽기/쓰기 섹션 알림은 저장에 성공한 뒤에 실행됩니다.

- 사이트 정체성(설정 → 일반): 사이트 아이콘(favicon/`apple-touch-icon`; `/favicon.ico`는 페이지를 렌더링하지 않고 해당 아이콘이나 기본 아이콘으로 리디렉션합니다), `site-logo` 블록용 사용자 지정 로고(SEO에 로고가 없으면 JSON-LD 로고로도 사용), 공개 로그인 경로/링크 표시 여부. 로그인 경로는 콘텐츠 및 아카이브 경로와 고유주소 잠금을 공유합니다. 레거시 충돌이 있으면 콘텐츠 경로를 유지하고, 관리자가 다른 경로를 저장할 때까지 비어 있는 첫 번째 예약된 공개 `/cms-login[-N]` 대체 경로를 사용합니다. 공개 페이지에서 `<html lang dir>`는 사이트 로캘을 따릅니다(사이트 레이아웃이 설정하는 `locals.lang`).
- 본문 이미지는 라이브러리의 WebP 크기, 고유 크기, 첫 이미지 이후의 지연 로딩을 바탕으로 `srcset`/`sizes`와 함께 제공됩니다(`domain/content/responsive-images.ts`). 임베드는 설정 → 임베드에서 추가·비활성화·정렬하며 기본값은 YouTube, Vimeo, X, Instagram입니다. 활성 코어 제공자를 목록 순서대로 확인한 뒤 플러그인 제공자를 확인합니다. URL 패턴은 전체 href에 적용되며 `^`로 시작하는 RE2 문법을 사용합니다. 공통 RE2JS 엔진은 입력 길이에 선형 시간으로 실행하며 역참조와 전후방 탐색은 지원하지 않습니다. 서버와 편집기는 2048자를 넘는 URL을 검사하지 않습니다. iframe 템플릿은 고정 HTTPS 출처와 패턴의 이름 있는 캡처만 사용할 수 있습니다. iframe 권한은 체크박스로 선택하며 허용된 지시문 이름만 저장할 수 있습니다(출처 목록 금지, 렌더링 시 재필터링). 본문 확장마다 설정을 한 번 읽으므로 다른 프로세스의 변경도 재시작 없이 반영됩니다. 일치하지 않는 주소는 일반 링크로 남습니다. 제공되는 본문은 동기화된 패턴, 임베드, 플러그인 블록(패턴 안의 블록도 렌더링되도록), 반응형 이미지 순서로 확장됩니다. 콘텐츠 저장과 패턴 저장 모두 플러그인 블록 속성을 검사합니다.
- 댓글과 글쓴이 공개 DTO의 아바타는 이메일이나 이메일 다이제스트 대신 서명된 `/avatars/…` URL만 담습니다. 웹의 같은 출처 프록시가 API에 전달하고, API가 공개 댓글/글쓴이 키를 이메일로 해석해 Gravatar를 제한 시간·크기·이미지 형식으로 가져와 캐시합니다. 실패하면 선택한 기본 스타일의 로컬 이미지로 대체합니다.

- 읽기 설정에서는 첫 페이지(최신 글, 또는 정적 페이지와 글 페이지), 페이지당 글 수, 피드 크기와 내용(전문 또는 요약), 날짜 형식, 시간대를 선택합니다. 정적 첫 페이지는 `/`에서 제공되며(자체 경로는 `/`로 리디렉션되고 정식 URL은 `/`입니다), 글 페이지는 고정 글을 먼저 나열합니다.
- 메뉴(`primary`, `footer` 위치)와 위젯(`sidebar`, `footer` 영역)은 코어 설정입니다. 메뉴 편집기에는 `appearance.manage`만 있으면 됩니다. 선택기는 게시된 항목만 반환하는 공개 API를 읽고, `GET /api/v1/admin/menus/targets`는 저장된 메뉴가 링크하는 게시 항목에 레이블을 붙입니다(`{ id, title, type }`, 게시 프로젝션에서 청크 단위로 읽음). 공개 메뉴와 위젯 DTO는 서버 측에서 대상을 해석하고 공개되지 않은 것은 모두 제외합니다. 메뉴나 위젯이 설정되지 않으면 테마는 페이지 목록과 카테고리로 대체합니다. 날짜 아카이브는 `/date/<year>[/<month>[/<day>]]`(사이트 시간대)에 있으며 색인되지 않습니다. 텍스트 위젯은 `**bold**`, `*italic*`, `[links](…)`를 지원하며, API는 HTML이 아니라 검사된 링크를 가진 런(`paragraphs`)을 반환합니다. 이미지 위젯은 미디어 라이브러리 이미지, 대체 텍스트, 검사된 링크를 받습니다. 사용자 지정 HTML 위젯은 없습니다(필터링되지 않은 HTML 권한이 존재하지 않습니다).
- 사이트 편집기: 템플릿, 파트, 전역 스타일에 대한 실행 취소/다시 실행(버튼, Ctrl/Cmd+Z, Ctrl/Cmd+Shift+Z; 텍스트 필드는 자체 실행 취소를 유지)이 있으며 저장 전에 실시간으로 미리 볼 수 있습니다. 목록 보기(선택, 이동, 삭제), 실시간 캔버스에서 클릭으로 선택(블록은 그곳에서만 `data-block-path`로 표시됨), 블록 설정, 사이드바의 검색 가능한 삽입기를 제공합니다. 공개 툴바는 보는 사람이 항목을 편집할 수 있을 때만(본인의 게시 항목은 `content.publish`, 다른 사람의 항목은 `content.editOthers` 필요) "편집"을 표시하고, `taxonomy.manage` 권한이 있으면 용어 아카이브에 "카테고리/태그 편집"을 표시합니다. 공개 메뉴와 위젯 DTO는 서버 측에서 대상을 해석하고 공개되지 않은 것은 모두 제외합니다. 메뉴나 위젯이 설정되지 않으면 테마는 페이지 목록과 카테고리로 대체합니다. 날짜 아카이브는 `/date/<year>[/<month>[/<day>]]`(사이트 시간대)에 있으며 색인되지 않습니다.
