# 확장된 작성 기능과 주소

상위 문서: [AGENTS.md](../../AGENTS.md)

- 이미 저장된 콘텐츠 경로는 사이트 시간대가 바뀌어도 다시 쓰지 않습니다. 새 저장과 명시적인 고유주소 재생성은 현재 사이트 시간대를 사용하며, 기존 트랜잭션을 통해 이전에 게시된 경로를 별칭으로 보존합니다. 날짜/일 필터는 로컬 날짜의 UTC 경계를 사용하고, 월별 아카이브는 MariaDB 시간대 테이블 없이 Intl로 같은 IANA 시간대에 맞춰 타임스탬프를 집계합니다.
- `menuOrder`는 페이지용 관리자 DTO/입력 필드입니다(공개 필드 아님). 페이지 목록, 대체 내비게이션, 부모 선택지는 이 값으로 정렬합니다. 공개 목록은 범위가 제한된 `include`/`exclude` ID 목록, `parent`(`0`은 루트), `orderby=date|modified|title|id|menu_order`, `order=asc|desc`를 받으며, 그 밖의 상태/가시성 필드는 계속 무시합니다. 이 필터를 사용하는 요청은 호환되지 않는 검색 가속기를 우회합니다. 마지막 페이지를 넘어선 라우팅 목록은 404를 반환하고, 테마 페이지 나누기에는 페이지 번호가 포함됩니다.
- `/comments/feed.xml`은 게시되고 휴지통에 없으며 보호되지 않은 글의 승인된 댓글만 게시하며, `?contentId=`로 글 하나를 선택합니다. 잠금 해제/세션 쿠키가 있어도 이메일이나 보류 중인 댓글은 노출되지 않으며, 피드는 캐시하지 않습니다. 작성자/사용자 정의 분류 사이트맵 청크도 같은 공개 콘텐츠 경계를 사용하며, 게시 자격이 있는 글이 없는 계정은 생략합니다.
- 미디어에는 관리자용 제목/설명 필드가 있으며, 공개 이미지 DTO는 바뀌지 않습니다. 관리자 콘텐츠 개수 엔드포인트는 상태마다 요약 목록을 가져오는 대신 유형당 그룹화된 쿼리 하나를 사용합니다.

- 단건 정식 조회는 선택적 세션을 받습니다. `content.readPrivate`는 관리자와 편집자에게 부여되며 사용자 정의 역할에도 지정할 수 있습니다. 비공개 조회는 목록, 피드, 사이트맵, Markdown에는 계속 나타나지 않으며, 공개 필드와 `noIndex`를 사용하고 공유 캐시나 브라우저 캐시를 쓰지 않습니다. 초안과 휴지통은 이 경로로 여전히 접근할 수 없습니다.
- 콘텐츠, 용어, 작성자 슬러그는 유니코드 글자/숫자와 결합 문자를 허용합니다. 생성되거나 제공된 슬러그는 NFC를 사용하며, 요청 경로는 그 외에는 퍼센트 인코딩된 바이트 정체성을 유지합니다. 공개 아카이브, 작성자, 피드, Markdown 별칭은 저장된 슬러그 표기로 리디렉션합니다. 경로 저장과 조회는 계속 정규 인코딩 바이트를 비교하며, 구분자, 쿼리/프래그먼트 구분 문자, 제어 문자를 포함한 디코딩된 경로 세그먼트는 거부합니다. 플러그인, 유형, 그 밖의 시스템 식별자는 계속 ASCII입니다. WXR 가져오기는 유니코드 슬러그와 용어 지정을 일관되게 정규화합니다. 슬러그로 만드는 모든 URL은 사이트맵, 메뉴, llms.txt, 목록 링크를 포함해 슬러그를 퍼센트 인코딩합니다(`archivePath`, `markdownPath`, `encodeURIComponent`). 슬러그 사용 가능 여부(`takenSlugs`)는 데이터베이스 열의 콜레이션으로 결정되며(`café`는 `cafe`를 점유함) 후보의 표기를 반환합니다. 테마 쿼리 선택기(카테고리/태그/작성자)와 슬러그별 템플릿 이름(`page-소식`)도 같은 유니코드 슬러그를 받습니다. 잠긴 보호 글은 `commentCount: 0`을 보고하며, 댓글 작성자 이름 길이(100)보다 긴 프로필 이름은 로그인 상태 댓글과 모더레이터 답글에서 줄여 사용합니다.

- 사이트 편집기는 공개 렌더러를 사용하는 실시간 데스크톱/모바일 미리보기를 제공합니다. 저장되지 않은 독립 쿼리 선택은 읽기 전용 폼 액션으로 해석하며, 오래된 요청은 취소합니다. 단일 템플릿은 게시된 콘텐츠를 미리 봅니다. 재사용 가능한 패턴은 관리자가 만든 부분을 포함해 이름 있는 템플릿 부분을 사용하며, 부분을 편집하면 모든 참조가 갱신됩니다.
- 역할에는 `subscriber`와 관리자가 정의한 역할이 있습니다. 역할 정의는 별도의 `role.<key>` 설정에 저장되며 내장 역할은 고정됩니다. 정의 저장/삭제, 계정 생성, 역할 지정은 `users.lock`을 공유하고, 삭제 시 구성원은 원자적으로 재지정되며, 프로필만 쓰는 작업은 이전에 읽은 역할을 다시 쓰지 않습니다. 인증된 프로필은 기존 세션과 API 토큰을 포함해 모든 요청에서 확인한 권한을 받습니다. 요청 본문의 권한은 절대 신뢰하지 않습니다. 플러그인 `access: 'admin'` 라우트는 `plugins.manage`가 필요합니다.
- 사용자 관리는 이메일 전달이 구성된 뒤에만 공개 가입을 활성화합니다. `/admin/register`는 일회용 비밀번호 초대를 보내며, 클라이언트는 역할이나 초기 비밀번호를 선택할 수 없습니다. 가입은 비밀번호 재설정의 속도 제한/캡차를 재사용하고 모든 새 계정은 구독자입니다. 이메일 변경에는 `users.manage`가 필요하며, 일반 프로필 변경은 역할과 확인된 권한을 유지합니다.
- 사용자 정의 분류 정의는 `taxonomy.definition.<key>` 설정을 사용합니다. `/api/v1/admin/taxonomy-types`가 정의를 나열/저장하고, 기존 분류 라우트가 그 용어를 관리합니다. 콘텐츠는 `extraTermIds`를 받으며, 공개/관리자 DTO는 엄격한 `extraTerms`를 명시적으로 투영합니다. 목록은 페이지 나누기와 전문 검색 전에 하위 용어를 포함한 `taxonomy`/`term` 쌍 필터를 받습니다. 이 필터에서는 Meilisearch를 우회합니다. 공개 아카이브는 `/taxonomy/<key>/<slug>`에 있습니다.
- 페이지는 관리자 전용 `parentId`를 받습니다. 저장소는 공유 고유주소 트랜잭션 안에서 페이지 상위 관계, 순환, 깊이를 검사합니다. 자식이 있는 페이지는 다른 콘텐츠 유형으로 바꿀 수 없습니다. `%pagename%`은 상위 슬러그를 포함하며, 새 사이트의 페이지 패턴은 `/%pagename%`입니다. 부모의 이름 변경/부모 변경/삭제는 영향받는 주소를 원자적으로 갱신하고 게시된 리디렉션을 보존합니다.
- 고유주소는 WordPress 토큰, 유니코드 리터럴, 선택적 마지막 슬래시를 받습니다. `%post_id%`는 이 CMS의 기존 UUID 식별자를 사용합니다. `%category%`는 이름, 그다음 id 순으로 처음 지정된 카테고리를 선택하고 상위 항목을 포함하며, 지정되지 않은 글은 `uncategorized`를 사용합니다. `%author%`는 공개 작성자 슬러그를 사용합니다. 공개 SvelteKit 레이아웃은 `trailingSlash = 'ignore'`를 사용하며, 정식 리디렉션은 API가 담당합니다.
- 카테고리/태그 접두사는 `/api/v1/admin/permalinks/archives`에서 따로 구성하며, 공개 상태는 `/api/v1/permalinks/archives`에서 읽습니다. 이전 접두사는 리디렉션됩니다. 아카이브 접두사와 콘텐츠 경로는 트랜잭션 잠금을 공유하며 양방향 충돌을 거부합니다. 정식 메타데이터, 메뉴, 용어 링크, 위젯, 사이트맵은 구성된 접두사를 사용합니다.
- 미디어는 시그니처로 MP3, WAV, Ogg 오디오를 지원하며, 공유 편집기의 오디오 노드와 사용 추적도 포함합니다. `POST /api/v1/admin/media/:id/edit`는 자르기 좌표를 검증하고 이미지 자르기/회전/뒤집기를 허용합니다. 편집하면 새 WebP 미디어 항목을 만들고 원본과 기존 콘텐츠 참조는 그대로 둡니다. 애니메이션 GIF 편집은 제공하지 않습니다.
- `20261105000000_custom_taxonomies`는 분류 키를 ENUM에서 VARCHAR로 바꾸며 용어는 삭제하지 않습니다. `20261106000000_page_hierarchy`는 인덱스와 자기 참조를 가진 null 허용 페이지 상위 관계를 추가합니다. 운영 마이그레이션 실행은 이 파일들의 준비 및 테스트와 별개입니다.
